# flutter_twin

The same repro trees as `../lib/demos.dart`, run in Flutter, so you can see
what each one should look like. `lib/demos.dart` is a copy of
`../lib/demos.dart` with Flutter imports.

```sh
cd flutter_twin
flutter create --platforms ios,android .   # once, to fill in the platform folders
flutter run
```

Checked with Flutter 3.44.5 on the iPhone 17 Pro Max simulator (iOS 26.1).
